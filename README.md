# TekneShop

Tekne ve denizcilik ekipmanları için demo e-ticaret vitrini (Next.js 16 + Tailwind 4).

## Geliştirme

```bash
npm install
npm run dev
```

Tarayıcı: [http://localhost:3001](http://localhost:3001) (3000 başka projede kullanılıyorsa)

## Sayfalar

- `/` — Ana sayfa (sol menü + vitrin)
- `/tekne` — Tekne ilanları (sıfır / ikinci el / kiralık)
- `/tekne/sifir`, `/tekne/ikinci-el`, … — Alt kategoriler
- `/parcalar` — Parça & ekipman (sıfır / ikinci el)
- `/urun/[slug]` — Parça detay

## Sonraki adımlar

- Sepet ve ödeme (iyzico / Stripe)
- Admin paneli
- Veritabanı (ürün stok)
- Gerçek ürün görselleri
- Domain: tekneshop.com
